1 Executive Summary
61/100
Needs Work

Kaufmann Architects has a clean, well-structured site with the SEO fundamentals in good shape: every page has a unique title and meta description, project pages live at their own URLs, schema markup is in place, and the canonical / OG / mobile setup is all correct. For a small studio that's a strong baseline most firms don't reach.

The biggest gap is one that quietly hurts every architecture firm: the imagery is invisible to search engines. Across the homepage, projects index, about page, and individual project pages, virtually every photo has empty alt text — so Google can't see the work that defines the practice. Combined with thin individual project copy, a missing homepage H1 keyword, and no dedicated service or location pages for searches like 'custom home architect Sacramento' or 'ADU architect Sacramento,' there's meaningful traffic the site isn't competing for yet.

6 Content Gap Recommendations

Topics and content types your competitors cover that you're missing.

Custom Home Architect — Sacramento landing page High Priority

Highest-intent commercial keyword for the practice; currently no page directly targeting it. The homepage tries to do too many jobs at once.

Recommended format: Service landing page with intro copy, process overview, 4-6 featured custom home projects, FAQ section.

ADU (Accessory Dwelling Unit) Architect — Sacramento High Priority

ADU search volume in California has grown sharply with state policy changes. Local searches like 'ADU architect Sacramento' have real traffic and are nearly unclaimed by direct service pages.

Recommended format: Dedicated service page covering ADU regulations, typical scopes, costs, examples.

Whole-House Remodel Architect High Priority

The studio clearly does this work (Land Park, Esparto, etc.) but has no page targeting the search term.

Recommended format: Service page + 2-3 in-depth case studies showing before/after, scope, timeline.

Neighborhood pages — East Sacramento, Land Park, Sierra Oaks Medium Priority

Sacramento home buyers search by neighborhood. Each has projects already in the portfolio that could anchor a local SEO page.

Recommended format: Short, useful neighborhood pages with project grid, local context, and a CTA.

Winery & Tasting Room Architect Medium Priority

A real differentiator (Twin Rocks, Heringer Winery) but undersold. Niche, lower competition, premium clients.

Recommended format: Niche service page with hospitality / agriculture context.

Educational articles for early-stage clients Medium Priority

Most prospective clients search informational queries before commercial ones. A small content library captures top-of-funnel and builds authority.

Recommended format: Short blog posts: 'Do I need an architect for a remodel?', 'How much does a custom home cost in Sacramento?', 'Architect vs. designer'.

Process / What to Expect page expansion Low Priority

The 'How We Work' page is good but light. Expanding it with a phase-by-phase breakdown helps both SEO and conversion.

Recommended format: Long-form guide with diagrams, deliverables per phase, typical timelines.

7 Prioritized Action Plan
Quick Wins do this week — under 2 hours each

  2. Add an H1 tag to every individual project page (currently missing) — use the project name + city.

  5. Expand the meta description on the projects page to include 'Sacramento' explicitly (currently mentions only 'western United States').
  6. Add 2-3 internal 'related projects' links at the bottom of each project page.
  7. Run all hero / portfolio images through a WebP conversion to cut page weight.
  8. Make sure every project URL is in the XML sitemap and request a fresh crawl in Google Search Console.
